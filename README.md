# Medical-Insurance-Uncleaned-Data---Pandas-Project-in-Python
## Overview
##### This project demonstrates the use of the Pandas library in Python for data manipulation, analysis, and processing. It includes practical examples of handling datasets, performing transformations, and extracting meaningful insights.
## Features
##### - Data loading and inspection
##### - Data cleaning and preprocessing
##### - Handling missing values
##### - Data filtering and selection
##### - Aggregation and grouping
##### - Basic data analysis and insights
##### - Exporting processed data
## Missing Values & Duplicate Values
#### Removed duplicate records using:
##### - Patient_ID
##### - Hospital_ID
##### - Policy_ID
##### - Email → default placeholder
##### - Patient_Name → "Unknown"
##### - F → Female , Mle → Male
## Technologies Used
##### Python
##### Pandas
##### NumPy
