# Medical Insurance Data Cleaning & Analysis Using Pandas
## Project Overview

##### This project focuses on cleaning, transforming, and analyzing a medical insurance dataset using Python and Pandas. The dataset contains demographic and health-related information such as age, gender, BMI, smoking status, region, and insurance charges.

##### The primary objective was to improve data quality, perform exploratory data analysis (EDA), and uncover key factors influencing medical insurance costs.

## Data Cleaning Process
### Data Exploration
##### - Examined dataset structure using Pandas functions.
##### - Reviewed data types, summary statistics, and data distributions.
##### - Identified missing values and inconsistencies.
## Data Preprocessing
##### - Removed duplicate records.
##### - Handled missing and invalid values.
##### - Standardized categorical variables for consistency.
##### - Corrected data formatting issues and ensured data quality.
## Data Validation
##### - Verified numerical and categorical data accuracy.
##### - Checked for outliers in variables such as BMI and insurance charges.
##### - Ensured consistency across all records.
## Exploratory Data Analysis (EDA)
### Analysis Performed
##### - Age-wise insurance cost analysis.
##### - BMI impact on medical charges.
##### - Smoking vs non-smoking cost comparison.
##### - Gender-based insurance charge analysis.
##### - Regional distribution of insurance expenses.
##### - Identification of key factors affecting healthcare costs.
## Key Insights
##### - Smoking status significantly increases insurance charges.
##### - Higher BMI levels are associated with increased medical expenses.
##### - Insurance costs generally rise with age.
##### - Regional differences contribute to variations in healthcare spending.
##### - Data analysis helps identify major drivers of insurance pricing.
